# 🔍 Python Port Scanner

A simple port scanner tool written in Python for learning networking and cybersecurity.

## ✨ Features
- Scan one or multiple IP addresses or domains.
- Scan a single port, multiple ports, or a range of ports.
- Choose scanning speed: normal, fast, or very fast.
- Display open ports and service names.
- Collect and save banner information.
- Show scanning progress in the terminal.

## 🛠️ Libraries
- `socket` — Network connections and port scanning.
- `threading` — Run scanning tasks concurrently.
- `IPy` — IP address validation.
- `pyfiglet` — ASCII art.
- `termcolor` — Colored terminal output.

## 📥 Installation
Install the required libraries:

```bash
python -m pip install pyfiglet termcolor IPy
```

## 🚀 Usage
Run the program:

```bash
python portscanner.py
```

Then enter the target address, port or port range, and scanning speed.

## 🎯 Purpose
This project was created to practice Python programming, networking concepts, and basic cybersecurity tool development.

## ⚠️ Disclaimer
Use this tool only on systems you own or have permission to scan.
